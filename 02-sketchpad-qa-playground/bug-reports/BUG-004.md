# BUG-004: Eraser size ignores the Size slider

| Field | Value |
|---|---|
| Severity | Medium |
| Priority | P2 |
| Component | Eraser |
| Environment | Sketchpad v1.0 with `?bugs=BUG-004`, Chrome (latest) |
| Related test case | TC-DRAW-004 |
| Reproducibility | Always (5/5) |

## Steps to reproduce
1. Draw a large filled area with the Pen at size 50.
2. Select the **Eraser** and set Size to 5. Drag across the drawing.
3. Set Size to 50 and drag again across a different area.

## Expected result
The eraser width follows the slider (twice the displayed size: 10 px at size 5 and 100 px at size 50).

## Actual result
Both passes erase a thin 5 px line. The slider has no effect on the eraser.

## Impact
Cleaning up large areas takes many strokes; users think the slider is broken.
