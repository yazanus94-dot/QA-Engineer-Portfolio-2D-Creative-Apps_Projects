# BUG-002: Rectangle and ellipse disappear when dragged right-to-left or bottom-to-top

| Field | Value |
|---|---|
| Severity | High |
| Priority | P1 |
| Component | Shapes |
| Environment | Sketchpad v1.0 with `?bugs=BUG-002`, Chrome (latest), Windows 11 |
| Related test case | TC-SHAP-001 |
| Reproducibility | Always (6/6) |

## Steps to reproduce
1. Select the **Rectangle** tool.
2. Press the mouse at (400, 300) and drag **up and to the left** to (300, 220). Release.
3. Repeat with drag directions: down-left and up-right.
4. Repeat with the **Ellipse** tool.

## Expected result
A shape is created in every drag direction, with the same size as a normal top-left to bottom-right drag.

## Actual result
Nothing is drawn for any drag that goes left or up. The object counter in the status bar does not change. Only top-left to bottom-right drags work.

## Impact
Designers draw shapes in all directions; the tool looks broken or unresponsive.

## Evidence / root-cause hint
Width/height are negative and the "too small" check rejects them: the rectangle is not normalised.
