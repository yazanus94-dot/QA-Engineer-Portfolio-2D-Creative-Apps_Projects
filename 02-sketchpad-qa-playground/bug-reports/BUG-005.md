# BUG-005: Brush size slider accepts 0, producing invisible strokes

| Field | Value |
|---|---|
| Severity | Low |
| Priority | P3 |
| Component | Pen / Size control |
| Environment | Sketchpad v1.0 with `?bugs=BUG-005`, Chrome (latest) |
| Related test case | TC-DRAW-002 |
| Reproducibility | Always (3/3) |

## Steps to reproduce
1. Move the Size slider fully to the left (value 0).
2. Draw with the Pen across the canvas.

## Expected result
The minimum size is 1 px and a visible line is drawn (boundary value: min = 1).

## Actual result
Size shows 0 and nothing is visible, but the object counter increases and Undo becomes enabled, so "empty" objects pollute the history.

## Impact
Confusing: it looks like drawing is broken. Each invisible stroke needs an extra Undo.
