# BUG-006: Redo stays available after drawing a new shape

| Field | Value |
|---|---|
| Severity | High |
| Priority | P1 |
| Component | History |
| Environment | Sketchpad v1.0 with `?bugs=BUG-006`, Chrome (latest) |
| Related test case | TC-HIST-002 |
| Reproducibility | Always (5/5) |

## Steps to reproduce
1. Draw shape A, then shape B.
2. Click **Undo** (shape B removed).
3. Draw a new shape C.
4. Observe the **Redo** button, then click it.

## Expected result
Redo is disabled after a new action (the old redo branch is discarded). Canvas keeps A and C.

## Actual result
Redo remains enabled. Clicking it replaces the canvas with an older state, so shape C disappears.

## Impact
Silent loss of the user's latest work.
